# KLCode for Claude Code

This directory contains the Claude Code manifest and GitHub marketplace catalog for [KLAA-Eng/KLCode-Skills](https://github.com/KLAA-Eng/KLCode-Skills).

The manifest exports 105 canonical skills, 16 command aliases and nine specialist roles. The existing canonical `requirements` skill supplies the seventeenth convenient command name. Four optional hook events use the explicitly declared `hooks/claude-hooks.json` adapter.

See the [shared plugin guide](../plugin/README.md#install-from-github-later) for installation commands and activation boundaries, and the [manifest notes](PLUGIN_SCHEMA_NOTES.md) before changing exports. Repository validation does not install, enable or activate the plugin. Claude-native validation remains unverified until a Claude executable is available.
