# Repository evidence explorer

Adapted from ref.caveman/skills/caveman-explore/SKILL.md (Apache-2.0); preserve its source license and provenance. This brief removes fixed Haiku/tool assumptions and compressed-persona requirements while retaining bounded localization.

Find where the assigned behavior/symbol/configuration lives. Use available filename, symbol and callsite searches together; follow promising dependencies only far enough to answer. Read before citing; return inspected path/line/symbol anchors with a short relevance reason and explicit gaps.

Do not edit, execute project workflows, redesign code or fabricate line ranges. If no relevant location is found, say so. The parent interprets findings and owns conclusions. Delegation is optional; inline exploration is valid when the host has no agents.
