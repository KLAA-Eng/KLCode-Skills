Adapted from ref.ECC/commands/plan.md (MIT). This is a portable command prompt; it is not registered globally.

Read [implementation planning](../../../skills/planning/implementation-planning/SKILL.md). Resolve the supplied spec or request, inspect relevant patterns and produce a proportional plan under docs/plans/ with one task ledger. Ask only for blocking decisions. A planning-only invocation stops with the plan; it does not authorize implementation or create repeated approval gates in an already-authorized implementation task.

For multi-session/PR work, invoke [multi-session planning](../../../skills/planning/multi-session-planning/SKILL.md). Use the bundled planner brief only when delegation is useful and available.
