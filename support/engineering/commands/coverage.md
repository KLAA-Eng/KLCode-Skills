# coverage

Adapted from `ref.ECC/commands/test-coverage.md`. Manual prompt template; no command registration or hook installation occurs here.

Read [test-governance](../../../skills/engineering/test-governance/SKILL.md).

Read existing coverage and risk goals and the [shared testing policy](../../../rules/common/testing.md). Locate meaningful untested behavior, error paths and consumer/provider gaps. Add tests only if the task authorizes edits, following the test-first default where applicable. Compare before/after evidence against project requirements or the changed-code target and explain measurement gaps; do not expand scope to chase repository-wide coverage.
