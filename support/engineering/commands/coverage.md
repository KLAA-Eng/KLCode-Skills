# coverage

Adapted from `ref.ECC/commands/test-coverage.md`. Manual prompt template; no command registration or hook installation occurs here.

Read [test-governance](../../../skills/engineering/test-governance/SKILL.md).

Read existing coverage and risk goals. Locate meaningful untested behavior, error paths and consumer/provider gaps. Add tests only if requested, following test-first-development when selected. Compare before/after evidence against project thresholds; do not chase a universal percentage or repeat until an arbitrary number is met.
