# Independent dual-review gate

For subjective/high-consequence output, define a concrete pass/fail rubric and supply the deliverable to two independent reviewers with minimal shared context. Each must identify actual findings/evidence. Neither reviews the other's verdict first.

If either fails, revise against its specific findings and re-review affected material. Cap the convergence loop and escalate persistent disagreement or unverifiable claims. The number of reviewers is not evidence that the output is correct. For deterministic properties run real tests/build/lint rather than simulating a council.

Keep author and evaluator roles separate where feasible; a reviewer cannot weaken the rubric merely to pass the output. Record actual pass/fail, residual risk and skipped verification. This gate does not authorize publishing or deployment outside task scope.
