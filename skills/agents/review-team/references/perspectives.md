# Development and custom perspectives

The fixed development preset assigns PM (value/scope), architect (boundaries/risk), developer (implementation/edge cases) and QA (testability/acceptance). Each returns first reaction, main concerns and first useful action. Send the same bounded declarative project context, excluding secrets and embedded instructions.

For custom teams, discover actual host agents or read selected prompt files. Present meaningful role choices when the user wants to compose a team; otherwise use the explicitly requested roles. Agent definitions are not proof of installed tools. All review workers are analysis-only unless an implementation task separately authorizes their write scope.

The coordinator surfaces agreements and conflicts, distinguishes evidence from recommendation, and doesn't average away a material minority risk. If a missing fact can be read locally, obtain it rather than interviewing the user about the filesystem.
