# Durable agent-ready brief

Source request and discussion supply context; this brief states the actionable contract without pretending inferred intent is confirmed.

- Category and concise summary.
- Current behavior and desired observable behavior.
- Relevant stable types/interfaces/configuration contracts.
- Acceptance criteria and practical evidence method.
- Scope exclusions, risks and known blockers.
- Existing PR/diff state when applicable; what remains to change.
- Authority/owner and source links.

Prefer stable symbols and behavior over line-specific implementation instructions. File/line citations remain useful as observed evidence, clearly dated/current rather than treated as timeless requirements.

For a bug include a reproducible symptom; for a PR distinguish finishing the submitted change, addressing review gaps and human merge readiness. Do not prescribe unnecessary layers or automatically promise test-first/coverage percentages.
