# Questionnaire

Interview the send, not the subject: establish the recipient's role/expertise/relationship and what decisions or facts the user needs back. Do not force the user to answer what only the recipient knows.

Write a requested Markdown questionnaire under `docs/knowledge/<topic>-questionnaire.md`. Include purpose, audience, how answers will be used, enough context for a new reader, expected effort/deadline when known, themed questions and a closing catch-all.

Put high-value questions first. Each asks one thing and has an answer space; use “why this matters” only when useful. Partial answers and “unknown” are valid. Separate factual evidence from preference questions and avoid leading wording that manufactures agreement.

Drafting does not authorize sending the questionnaire to anyone. Return the file and its intended use.
