# Compare radically different interfaces

For consequential interface decisions, frame the constraints, observable contract and dependency types. Explore distinct constraints: smallest caller surface, flexibility for established variations, easiest common caller, or ports/adapters for genuine I/O boundaries.

When delegation is available and useful, give independent agents isolated briefs rather than the preferred answer. Otherwise compare alternatives sequentially. Each returns contract/types, usage, hidden complexity, dependency strategy, tradeoffs and evidence limits.

Compare depth, locality, seam placement, migration effort and actual callers. Recommend a design or justified hybrid; do not turn three sketches into three production frameworks. Use ordinary domain vocabulary rather than enforcing a new lexicon.
