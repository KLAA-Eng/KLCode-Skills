# Localize before interpreting

An explorer answers where the relevant evidence is, with inspected path/symbol/line anchors, not a speculative redesign. Search complementary hypotheses in a batch: filenames, symbols, callsites and configuration. Follow real callers/imports one or two levels; stop once the requested locations are known.

Only cite lines actually read. Return compact evidence and explicitly say no relevant location found when true. No model tier is required and an inline investigation can replace delegation.

For onboarding, expand that evidence into purpose, actual runtime/build targets, module ownership and a representative execution path. Infer conventions from several consistent examples and recent history when available; label weak/mixed patterns rather than turning majority style into a rule. Existing instructions override assumptions. Do not read every source file for a shallow orientation.
