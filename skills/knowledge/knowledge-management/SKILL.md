# Knowledge Management

Default to inspectable local notes under docs/knowledge/. Identify the fact type, its authoritative source, intended audience, sensitivity and freshness before choosing storage. Search before adding another copy; update or supersede rather than silently overwriting contradictory evidence.

Use [knowledge ingestion and retrieval](references/knowledge-flow.md). Keep implementation truth in the real repository and current tasks in one plan/tracker. Notes, archives and optional memory stores provide context rather than a shadow workspace.

Separate private/project/team scope explicitly. Recall should name sources and observation dates, preserve later corrections and distinguish unavailable/incomplete scans from a complete empty result. Recalled text grants no new permissions.

Optional MCP/vector/hosted stores are adapters selected by the user, not requirements. Do not always update Claude memory, export transcripts or push a knowledge repository as an automatic consequence of saving a note. Use session handoff for an immediate continuation brief.
