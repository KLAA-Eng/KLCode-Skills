# Ingest, retrieve and curate

Classify: durable decision, confirmed fact, reference, lesson, preference, session context or active task. Store in its owner: decisions in docs/decisions, specs/contracts in docs/specs, current tasks in one plan/tracker, knowledge notes in docs/knowledge.

Deduplicate by concept and source rather than title alone. Link the owning source, observation date, what was actually checked, uncertainty and intended audience. A concise index can aid discovery; avoid mirroring every document into several memory systems.

On a correction, retain provenance and mark what supersedes prior information. Search relevance is not freshness. Source failures, truncated scans and unknown access are distinct from an empty complete result.

When optional host memory/MCP/vector/external storage is selected, document its scope and consistency boundary. Do not automatically export transcripts, sync private data, push Git or create cloud accounts. Never treat the archive as the live code checkout or a second task authority.
