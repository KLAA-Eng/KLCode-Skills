# Evidence-backed developmental feedback

Identify the artifact and requested scope. Review problem/question, literature context, methods/reproducibility, data/evidence, analysis/baselines, results/interpretation, limitations, writing/definitions and citation support.

Each finding: relevant excerpt/section or source pointer, interpretation, uncertainty, consequence and concrete revision. Use N/A for irrelevant dimensions and missing for unavailable evidence; neither is an automatic low score. Distinguish a methodological flaw from a poorly reported method.

A 1–5 developmental rating can summarize a dimension if the scale is agreed and anchors are clear, but is not a person score or automatic publishing/funding verdict. Avoid journal prestige, citation counts and institutional identity as proxies for the work's merit.

For structured calibration, use the imported evaluation framework and local tooling. These preserve bounded schemas, content-validity warnings, evidence traceability, disagreement, weight sensitivity and process checks. Structural validation does not certify an assessment instrument. Organizational use must respect the responsible-assessment reference.
