# Premium Web Design

This is the explicitly selected visual direction for this surface. Apply its aesthetic rules within that scope; do not combine contradictory alternative styles. Existing brand requirements, truthful content, accessibility and reduced-motion behavior take precedence. Verify fonts, icons, dependencies and assets actually exist; source examples do not authorize installing packages or inventing evidence.

Choose one surface archetype (ethereal glass, editorial luxury or soft structuralism) and one layout (asymmetric bento, z-axis cascade or editorial split) according to the brief. Read [premium specification](references/premium-specification.md) for its nested bezel geometry, pill CTA/icon treatment, floating navigation and motion recipes.

The nested outer-shell/inner-core treatment is intentional in this mode; it is not a default for other styles. Use concentric radii derived from padding and keep visual layers from becoming unnecessary interaction layers. A decorative icon circle inside a button is not another nested interactive button.

On small screens flatten overlapping/rotated layouts and preserve target sizes. Keep menu labeling, Escape/close, focus management and scroll behavior usable. Font/icon recommendations must be available and properly licensed before use.

Use transform/opacity for movement, limited backdrop blur, and a coherent z-index scheme. Under reduced motion present static end states and readable content; do not hide elements indefinitely behind reveal scripts. Verify the layout and interaction path in actual renders before completion.
