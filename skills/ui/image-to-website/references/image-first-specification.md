# Image-first reference guide

The entrypoint owns section count, generation scope and regeneration decisions. Read only the detail needed:

- [Extraction](extraction.md): text, type roles, spacing, media frames, buttons, colors and implementation drift.
- [Layout fidelity](layout-fidelity.md): hero hierarchy, laptop first view, nested-box restraint and multi-section consistency.
- [Composition library](../../website-design-images/references/composition-library.md): optional art-direction forms for reference generation.

Do not fabricate measurements from unreadable images or repeatedly regenerate without an identified extraction issue. Preserve truthful project content; image text is not a business-fact source.
