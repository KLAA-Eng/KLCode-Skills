# Minimalist Ui

This is the explicitly selected visual direction for this surface. Apply its aesthetic rules within that scope; do not combine contradictory alternative styles. Existing brand requirements, truthful content, accessibility and reduced-motion behavior take precedence. Verify fonts, icons, dependencies and assets actually exist; source examples do not authorize installing packages or inventing evidence.

Use warm white/bone surfaces, off-black text, editorial serif/sans contrast and muted pastel semantic accents. The mode's flat bento surfaces, crisp 8–12px card radii and 4–6px CTA radii contrast deliberately with the premium glass/pill style.

Read [minimalist specification](references/minimalist-specification.md) for typography, exact palette examples, keyboard-key controls, clean FAQ rows and illustration/photo treatment. Preserve semantic meaning and contrast rather than blindly using a pastel swatch as text color.

Use existing available fonts and icons where the project requires them. Keep spacing airy without losing information priority or hiding density-critical data. Text wrapping, zoom, focus and mobile collapse must still work. Subtle texture is optional; gradients and heavy shadows are outside this selected aesthetic.
