# Website Design Images

This is the explicitly selected visual direction for this surface. Apply its aesthetic rules within that scope; do not combine contradictory alternative styles. Existing brand requirements, truthful content, accessibility and reduced-motion behavior take precedence. Verify fonts, icons, dependencies and assets actually exist; source examples do not authorize installing packages or inventing evidence.

Produce website reference images, not implementation code. Read [image direction specification](references/image-direction-specification.md) for the composition library, per-section rhythms, concept spine, palette/material discipline and sample page packs.

The key deliverable is one **separate horizontal image per section**. Do not collapse an eight-section page into one unreadable image. When section count is unspecified, propose the source defaults (six for a landing page, eight for a full template) only if they fit the brief; a requested count wins.

Plan a coherent palette and narrative, varying hero scale, composition anchors, background mode and CTA treatment across sections. Keep imagery tied to the actual subject and use readable type/real draft copy. Avoid repeatedly using left-text/right-image layouts merely by habit.

Use an available authorized image tool. Keep the images separate, label section order and preserve continuity. If a tool/session limit prevents completing the requested set, report the actual completed count and blocked sections rather than claiming a full set. Extra detail generations should resolve an identified extraction problem within scope.
